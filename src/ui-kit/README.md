# ui-kit

Composants graphiques génériques, sans logique métier ni import d'autres modules : `Button`, `Input`,
`Textarea`, `Select`, `Checkbox`, `Field`, `Section`, `Badge`, `Kbd`, `Dialog` (Radix), `ContextMenu` (menu au clic droit, EVO-010),
`LocalizedTextInput` (une saisie par langue), `FieldErrors` (messages d'erreur d'un champ : `p.text-sm.text-rose-600[role=alert]`, EVO-025), `cn` (fusion de classes Tailwind).

- Style : Tailwind v4, palette slate + indigo, aéré. Composants copiés et maîtrisés (esprit shadcn/ui).
- Aucun texte d'interface en dur : les libellés sont passés par props.
