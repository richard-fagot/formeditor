# ui-kit

Composants graphiques génériques, sans logique métier ni import d'autres modules : `Button`, `Input`,
`Textarea`, `Select`, `Checkbox`, `Field`, `Section`, `Badge`, `Kbd`, `Dialog` (Radix),
`LocalizedTextInput` (une saisie par langue), `cn` (fusion de classes Tailwind).

- Style : Tailwind v4, palette slate + indigo, aéré. Composants copiés et maîtrisés (esprit shadcn/ui).
- Aucun texte d'interface en dur : les libellés sont passés par props.
