# plugins/question-types/tristate

Type « tri-state » (`type: "tristate"`) : réponse `true` / `false` / `"unknown"` (ou `"other"` avec
l'option « Autre », libellé éditable). Libellés « Oui / Non / Ne sait pas » par défaut, ou `labelSet`
(jeu de libellés `kind: "tristate"` de la bibliothèque, édité dans l'onglet Bibliothèque). Raccourci : 3.
