# plugins/question-types/number

Type « nombre » (`type: "number"`) : `numberKind` (`real`, `natural`, `integer`), `min` / `max` (nombre
littéral ou expression), `decimals`, `unit` (multilingue). Raccourci par défaut : R.
Aperçu `<réel>`, `<entier naturel>`, `<entier relatif>` suivi de l'unité. Validation : `core/validation`.
