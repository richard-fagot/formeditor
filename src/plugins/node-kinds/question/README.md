# plugins/node-kinds/question

Nœud question (locale ou référence de bibliothèque). Forme : rectangle blanc. L'aperçu du type est
rendu par le plugin du type de question, transmis par l'éditeur (`ShapeProps.typePlugin`).
Les propriétés et la page de prévisualisation des questions sont gérées par `ui/properties` et `ui/preview`
à partir des plugins de types de questions.
