# plugins/node-kinds/block

Instance de bloc (`kind: "block"`, `ref`, `alias`). Forme : rectangle ambre en pointillés : titre du bloc, alias,
bouton « Déplier » qui liste en lecture seule ses questions (`alias.cle`) et ses sorties (état local du composant).
Les poignées de sortie et les propriétés (alias) sont fournies par l'éditeur (`ui/diagram`, `ui/properties`).
